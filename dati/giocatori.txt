# ELENCO DEI GIOCATORI ISCRITTI
# =============================
#
# Un giocatore per riga, con tre dati separati dal punto e virgola:
#
#     codice ; classifica ; circolo
#
#   codice      il codice anonimo del giocatore (userid). Non scrivere
#               nomi e cognomi: questo file puo' finire in internet.
#   classifica  una di quelle scritte in dati/classifiche.txt
#               (per esempio 3.4 oppure 4.NC; va bene anche 3,4 con la virgola)
#   circolo     il nome del circolo; scriverlo sempre allo stesso modo
#               per tutti i giocatori dello stesso circolo
#
# Le righe che cominciano con # sono commenti e vengono ignorate.
# Le righe vuote vengono ignorate.
#
