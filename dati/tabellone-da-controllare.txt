# TABELLONE DA CONTROLLARE
# ========================
#
# Qui si scrive un tabellone fatto (o corretto) a mano, per farlo
# controllare dal programma con le regole del manuale.
# Il controllo si avvia con:   py tabelloni.py controlla
# (oppure con il pulsante "Controlla un tabellone..." della finestra).
# Va bene anche copiare qui il file risultati/tabellone.txt e correggerlo.
#
# TABELLONE DI SELEZIONE: un giocatore per riga, dall'alto in basso, con il
# turno in cui entra in gara:
#     turno 4  (1) G001    la testa di serie n. 1, che entra al quarto turno
#     turno 2      G007    il codice di un giocatore di dati/giocatori.txt
#     turno 1      q       un qualificato entrante, al primo turno
# Dopo il codice si puo' scrivere quello che si vuole (classifica, circolo).
# Il programma ricostruisce gli incontri: due vicini pronti per lo stesso
# turno si incontrano, e il vincitore e' pronto per il turno dopo.
#
# TABELLONE DI ESTRAZIONE: un posto per riga, dall'alto in basso:
#     G001            il codice di un giocatore di dati/giocatori.txt
#     (1) G001        un giocatore testa di serie numero 1
#     posto libero    un posto libero (bye)
#     q               il posto di un qualificato entrante
# Prima si puo' scrivere il numero del posto.
#
# Le righe vuote servono solo a separare le parti del tabellone.
#
# ESEMPIO CON DUE ERRORI MESSI APPOSTA, per vedere come funziona:
#   - G010 (3.4) entra al primo turno, mentre G013 (3.5) entra al secondo;
#   - le teste di serie n. 1 e n. 2 sono scambiate di posto.

turno 3        G005       3.2   Tennis Valle
turno 2        G007       3.3   CT Lago Blu
turno 1        G014       3.5   Circolo Pineta
turno 1        q  (qualificato entrante)

turno 3        G008       3.3   TC Collina
turno 2        G012       3.4   TC Collina
turno 2        q  (qualificato entrante)
