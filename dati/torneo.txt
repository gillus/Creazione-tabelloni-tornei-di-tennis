# IMPOSTAZIONI DEL TORNEO
# =======================
#
# Una impostazione per riga, nella forma:
#
#     nome dell'impostazione = valore
#
# Le righe che cominciano con # sono commenti e vengono ignorate.
#
#   nome                  il nome del torneo, come deve comparire sul tabellone
#                         (obbligatorio)
#   gara                  la gara, per esempio "Singolare maschile" (obbligatorio)
#   date                  le date del torneo, scritte come si vuole (facoltativo)
#   tipo                  "selezione" (i giocatori entrano in tre o piu' turni,
#                         secondo la classifica) oppure "estrazione" (tutti
#                         entrano al primo o al secondo turno) oppure
#                         "integrale" (tabellone finale di estrazione a sorteggio
#                         integrale: dopo le teste di serie tutto si decide per
#                         sorteggio, anche i posti dei qualificati entranti, che si
#                         possono incontrare tra loro; solo con qualificati
#                         uscenti = 1). Facoltativo; se manca vale "selezione"
#   qualificati entranti  quanti giocatori arrivano da un tabellone precedente
#                         (facoltativo; se manca vale 0)
#   qualificati uscenti   quanti giocatori escono da questo tabellone per andare
#                         al successivo; 1 vuol dire che il tabellone da' il vincitore
#                         (facoltativo; se manca vale 1). Se non e' 1, 2, 4, 8, 16...
#                         (per esempio 3, 5 o 6) il tabellone viene diviso in
#                         sezioni, una per ogni qualificato (capitolo III del manuale)
#   teste di serie        quante teste di serie fare (facoltativo; se manca le
#                         propone il programma, secondo le regole del manuale).
#                         Con le sezioni deve essere un multiplo del numero delle
#                         sezioni (lo stesso numero di teste di serie in ognuna)
#
# Solo per il tabellone di selezione, e solo se si vuole cambiare la "scala"
# proposta dal programma (chi entra in ogni turno), una riga per turno:
#
#   turno 3 = 3 (4.1), 1 (4.2)
#   turno 2 = 4 (4.3)
#   turno 1 = coppie 4 (4.4)+q
#
# Prima del punto e virgola, i giocatori che entrano in quel turno contro un
# vincitore del turno prima; dopo "coppie", le coppie che entrano insieme e
# giocano tra loro: "4 (4.4)+q" sono quattro coppie di un (4.4) e un
# qualificato entrante, "1 (4.6)+(4.6)" una coppia di due (4.6). Per esempio:
#   turno 2 = 1 (2.6); coppie 2 (2.7)+q, 1 (2.8)+q
# Il programma mostra sempre la scala che usa, scritta cosi': si puo' copiare
# qui e cambiare.
#
# Qui sotto c'e' un torneo DI FANTASIA, solo per provare il programma: un
# tabellone di terza categoria che qualifica 4 giocatori, con 4 qualificati
# entranti da un tabellone di quarta categoria.

nome = Torneo di prova
gara = Singolare maschile
date = dal 1 al 10 ottobre
qualificati entranti = 4
qualificati uscenti = 4
